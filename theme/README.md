# BonosPremium Theme

Tema personalizado para WordPress + WooCommerce.
Sin dependencia de Elementor. Reutilizable para todas las tiendas.

## Variables CSS
```
--bp-primary: color principal
--bp-header-bg: fondo del header
--bp-user-menu-text: color texto menú usuario
```

## Archivos clave
- `assets/css/main.css` - Estilos principales
- `assets/js/main.js` - JavaScript
- `functions.php` - Configuración del tema
- `header.php` - Header
- `footer.php` - Footer con ondas SVG
- `woocommerce/` - Templates WooCommerce personalizados
